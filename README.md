# Trabalho PEP-8 - Agenda de Tarefas

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma aplicação de Agenda de Tarefas utilizando Python.

O trabalho foi desenvolvido com o objetivo de demonstrar a importância da organização, legibilidade e padronização do código, utilizando como referência as boas práticas estabelecidas pela PEP 8.

O projeto possui duas versões:

- Versão não refatorada: código original, desenvolvido antes da aplicação das boas práticas de organização e padronização.
- Versão refatorada: código reorganizado e ajustado seguindo as recomendações da PEP 8.

## Objetivo

O objetivo do trabalho é comparar o código antes e depois da refatoração, identificando melhorias relacionadas à organização e à qualidade do código.

A aplicação permite:

- Cadastrar tarefas;
- Marcar tarefas como concluídas;
- Listar tarefas pendentes;
- Listar todas as tarefas;
- Encerrar o programa.
